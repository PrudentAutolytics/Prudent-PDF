Capabilities

Everything you need

Built for compliance, legal, and operations teams who process sensitive documents at scale.

Automatic PII Detection
Detects names, addresses, ID numbers, dates of birth, email addresses, phone numbers and more — across all page types.
Permanent Redaction
Black-box redactions are burned directly into the PDF. No metadata, no hidden layers, no recoverable data.
Side-by-side Viewer
Compare original and redacted versions in one screen. Verify every redaction before downloading.
Full Audit History
Every job is logged with cost breakdown, page count, and timestamp. Export to CSV for compliance records.
PII Field Export
Download detected fields as CSV — entity types, confidence scores, page numbers — for downstream audit workflows.
Secure Azure Storage
Private Azure Blob Storage with SAS-based time-limited access. Auto-deleted after 7 days. Zero public access.

For developers

Integrate via
REST API

Business and Enterprise plans include full API access. Submit jobs, poll status, and retrieve redacted documents programmatically — from any language or platform.

Bearer token authentication — scoped API keys per user
Inherits plan limits — quotas enforced server-side
JSON response — with extracted PII fields and confidence scores
Webhook callback — notified when job completes
Request API access
# Submit a redaction job curl -X POST \ /api/jobs-submit \ -H "Authorization: Bearer ppk_..." \ -H "Content-Type: application/json" \ -d '{ "email": "you@company.com", "fileName": "contract.pdf", "fileBase64":"<base64 encoded PDF>" }' # Response { "jobId": "j_abc123", "status": "queued", "pageCount": 8, "costTotal": 0.344, "resultUrl": "https://..." }
